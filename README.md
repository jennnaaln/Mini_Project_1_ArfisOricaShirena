# Mini_Project_1_ArfisOricaShirena
Sistem pengolahan data cuaca 

#Penjelasan Program

Sistem pengolahan data cuaca ini pada dasarnya adalah pencatatan dan pengelompokkan cuaca berdasarkan angka suhu. User memasukkaan nilai suhu satu persatu lalu mengetik "selesai" setelah data suhu sudah selesai dimasukkan. Selanjutnya program akan mengelompokkan suhu ke dalam beberapa kategori cuaca; dingin, sejuk, hangat, panas, panas terik dan suhu ekstrem. User juga dapat menghapus data jika terjadi kesalahan input data atau menambah data baru sebelum hasil akhirnya dicetak.
